# AgenticTeacher：RTX 5070 Ti 实测与回答消融

测试日期：2026-09-04  
测试范围：单机自部署的文档 Index、RAG 检索，以及当前配置的 DeepSeek 云端生成  
结论性质：MVP 实测，不是生产容量承诺

## 1. 摘要

- 一份 1.07 MiB 的中文量子力学 Markdown 教材完成全链路 Index 用时 **20.27 s**，生成 **736 个父块 / 1,986 个子块**，约 **98 子块/s**。
- 6 个物理专业查询各重复 3 次，`/v1/retrieve` 的客户端端到端延迟为 **P50 0.93 s、P95 0.98 s**。
- 查询阶段的 Qwen3 Reranker 平均耗时 **0.85 s**，约占服务端检索耗时的 **94%**，是当前最明确的性能瓶颈。
- 两道专业题的消融结果显示：无 RAG 时模型可以依靠世界知识给出完整答案，但没有教材引用且更容易超出长度约束；只提供子块时回答较简洁，但公式推导和符号上下文容易碎片化；返回完整父块时，教材符号体系和推导连续性最好。
- Agentic 三轮检索能把复合问题拆成不同知识面继续搜索，但会增加云端调用成本；当前充分性判断还存在过于保守和瞬态 5xx 的问题，需要以 Golden Set 校准。

## 2. 测试环境

| 项目 | 实测配置 |
|---|---|
| GPU | NVIDIA GeForce RTX 5070 Ti，15,872 MiB |
| PyTorch | 2.14.0+cu130 |
| 推理设备 / 精度 | `cuda` / `bfloat16` |
| Embedding | Qwen/Qwen3-Embedding-0.6B |
| Reranker | Qwen/Qwen3-Reranker-0.6B |
| RAG | LightRAG 1.5.7 + Qdrant 1.13.2 client |
| 分块 | 父块按 Markdown 小节/段落组织，子块 512 字符 |
| 检索参数 | 初始 TopK 16，Reranker 最终 TopK 4，再映射并去重父块 |

以上是成功执行基准时的环境快照。本轮整理报告时，Codex 沙箱无法访问 NVIDIA 设备和 Docker socket，后端也未能从沙箱内连接，因此本报告没有把后续只读复核误算为新的重复实验；这不等同于宿主机驱动故障。复现实验前应在宿主机确认 NVIDIA 驱动、Docker GPU runtime、API ready 状态和模型实际落在 CUDA。

## 3. Index 性能

测试输入：

- 文件：`data/量子力学 (第三版) (井孝功, 赵永芳).md`
- 大小：1,119,658 bytes（约 1.07 MiB）
- 行数：22,671
- Workspace：`physics`

`POST /v1/index` 的真实返回：

| 指标 | 结果 |
|---|---:|
| 全链路耗时 | 20,273.95 ms |
| 成功文件数 | 1 |
| 父块数 | 736 |
| 子块数 / 新增向量块 | 1,986 |
| 子块长度 | 512 字符 |
| 警告 | 0 |
| 子块处理吞吐 | 约 98 子块/s |
| 输入字节吞吐 | 约 55 KiB/s |

这里的 20.27 s 包含 Markdown 解析、父子切分、Qwen3 Embedding 推理以及 LightRAG/Qdrant 写入，不是单独的 GPU kernel benchmark。量子力学教材已保留在 `physics` workspace 中。

## 4. 查询性能

问题集包含 6 个物理专业查询：

1. 麦克斯韦方程组的微分形式
2. 位移电流的物理意义
3. 电介质中的电磁波传播速度
4. 一维无限深势阱的能级和波函数
5. 厄米算符的本征值为什么是实数
6. 自旋角动量与泡利矩阵的关系

每个问题对热服务连续调用 3 次，共 18 次。计时范围是从测试客户端发出 `POST /v1/retrieve` 到完整 JSON 响应返回，不包含查询改写和最终云端回答生成。

| 指标 | 结果 |
|---|---:|
| 客户端端到端平均 | 927.50 ms |
| 客户端 P50 | 930.34 ms |
| 客户端 P95 | 980.09 ms |
| LightRAG 检索平均 | 903.63 ms |
| Qwen3 Reranker 平均 | 848.32 ms |
| Reranker / 检索耗时 | 约 94% |

在本测试规模下，热查询稳定在 1 秒内。麦克斯韦方程、无限深势阱和厄米算符等查询能够稳定命中对应章节；但“位移电流的物理意义”的 Top-1 是 `# 10.14 束缚电荷的电流`，不是最理想章节。这说明模型大小不能单独解释全部误差，查询表述、教材标题、候选召回、Reranker 校准和父块去重策略都需要通过 Golden Set 联合评估。

## 5. 回答消融设计

固定使用同一云端生成配置，比较四种上下文方式：

| 模式 | 提供给生成模型的资料 |
|---|---|
| 无 RAG | 不提供教材，只使用模型世界知识 |
| 仅子块 | 只提供 Reranker 命中的子块文本 |
| 父块 RAG | 将命中子块映射到完整父块，单轮检索 |
| Agentic RAG | Rewrite → Retrieve → Assess，最多三轮，最后以完整父块生成 |

注意：本次消融脚本中的 `Assess` 调用了当前云端 provider，是为了观察三轮反思行为；而 `PROJECT.txt` 的目标生产架构规定 Grade 应完全使用本地归一化分数规则、不调用大模型。因此这组 Agentic 结果属于**实验编排**，不能当作最终 Grade 架构的验收结果。

自动统计的“关键词覆盖”和“公式块数”仅用于同题横向观察，不等同于事实正确率、人工教学质量评分或引用真实性评分。

## 6. 消融结果 A：麦克斯韦方程与电磁波

问题：从麦克斯韦方程组推导真空电磁波方程，并说明电介质中传播速度和电、磁场振幅关系。控制在 600 字内。

| 模式 | 生成耗时 | 回答字符 | 公式块 | 关键词覆盖 | 引用 |
|---|---:|---:|---:|---:|---:|
| 无 RAG | 8.09 s | 1,993 | 17 | 7/8 | 0 |
| 仅子块 | 17.47 s | 1,585 | 11 | 6/8 | 0 |
| 父块 RAG | 11.72 s | 1,237 | 9 | 7/8 | 0 |
| Agentic RAG | 11.60 s | 1,360 | 12 | 5/8 | 0 |

观察：

- 无 RAG 的知识内容完整，但明显超出长度要求，且无法追溯到教材。
- 仅子块能够给出正确的波动方程和振幅关系，但上下文碎片化，遗漏了部分教材术语。
- 父块 RAG 最紧凑地覆盖真空波动方程、`v=c/√κ` 与 `E₀=vB₀`，公式和解释的上下文最连贯。
- Agentic 模式实际执行 3 轮：先检索综合问题，再聚焦真空推导，最后补充介质传播速度和振幅关系；第三轮判定充分。它展示了多知识面补检索能力，但最终答案没有产生 `[Sx]` 引用，引用约束仍需加强。

三轮检索轨迹：

1. `麦克斯韦方程组推导真空电磁波方程及电介质中传播速度与电磁场振幅关系` → 不充分
2. `如何从麦克斯韦方程组推导出真空中的电磁波波动方程` → 不充分
3. `电介质中的电磁波传播速度及电场磁场振幅关系推导` → 充分

## 7. 消融结果 B：简并与非简并定态微扰

问题：比较非简并与简并定态微扰理论的一阶能量修正，并说明简并情形为什么需要对角化扰动矩阵。控制在 600 字内。

| 模式 | 生成耗时 | 回答字符 | 公式块 | 关键词覆盖 | 引用 |
|---|---:|---:|---:|---:|---:|
| 无 RAG | 11.59 s | 1,062 | 3 | 8/8 | 0 |
| 仅子块 | 9.05 s | 696 | 1 | 7/8 | `[S1][S2]` |
| 父块 RAG | 11.06 s | 938 | 3 | 7/8 | `[S1]` |
| Agentic RAG | 6.61 s | 869 | 2 | 6/8 | `[S3]` |

观察：

- 无 RAG 的解释完整，但没有教材依据，并且超过长度约束。
- 仅子块最简洁且能引用两个片段，但没有呈现父块中完整的扰动矩阵本征方程。
- 父块 RAG 保留教材符号体系、久期方程和能级劈裂逻辑，专业细节最完整。
- Agentic 模式通过查询改写得到聚焦回答并保留引用，但三轮都被判定“不充分”；最终仍用第三轮父块生成了正确的核心解释。这说明充分性判断过于保守，继续检索不一定带来额外有效信息。

## 8. 结论与下一步

当前证据支持以下工程判断：

1. RTX 5070 Ti 可以支撑 0.6B 级 Qwen Embedding/Reranker 的单机 MVP，1.07 MiB 中文教材约 20 秒完成 Index，热检索约 1 秒。
2. 查询瓶颈主要在 Reranker，而不是向量召回。下一步应优先评估候选数、批处理、半精度/编译优化与更轻量 Reranker，而不是盲目更换 Embedding。
3. 父子块机制的主要收益是符号一致、公式推导完整和来源可追溯，而不保证所有启发式关键词分数都提高。
4. Agentic 多轮适合覆盖复合问题，但应在收益、延迟和云端调用成本之间设置明确停止条件；生产 Grade 应回归 `PROJECT.txt` 规定的本地确定性规则，并用 Golden Set 校准。
5. 生成端需要加强引用约束和格式校验；对结构化判断增加幂等重试、JSON 修复和可观测错误码。

### 局限性

- Index 只测试了 1 个 Markdown 文件；未覆盖 PDF/PPT、扫描页、OCR 和多文件并发。
- 查询基准只有 6 个问题、18 次热请求；未测试冷启动、并发用户、长时间稳定性和显存峰值。
- 回答消融只有 2 道题，云端生成具有随机性，且没有盲评教师评分。
- 生成耗时受供应商网络、排队和模型状态影响，不能直接归因于本地 RTX 5070 Ti。
- 关键词覆盖是启发式统计，不能替代事实性、完整性、教学有效性和引用一致性的人工评价。
- 一次 `/assess` 曾瞬态返回 502，重试后成功；该链路仍需稳定性治理。

### 建议的下一轮验收

- 建立不少于 50 题的物理 Golden Set，标注正确章节/父块并报告 Recall@4、MRR、nDCG 和无答案准确率。
- 分别测量冷/热 Index、Embedding、Qdrant 写入、召回和 Reranker 的 GPU 时间、CPU 时间、显存峰值。
- 进行 1/4/8 并发的 P50/P95/P99 与错误率测试。
- 对同一消融题固定 temperature/seed（供应商支持时），每个模式重复至少 5 次，并由教师盲评正确性、完整性、引用一致性和讲解质量。
